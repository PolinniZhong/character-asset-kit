# 通用提示词框架（blindbox3d profile · v1）

> 可直接复制的提示词模板。占位符：`{身份块}`＝规格卡身份签名的完整中文描述；`{CODE}`＝角色代号（只用于文件名，不入图）。
> 所有模板遵循同一结构：**通用头（风格/材质/比例/光）→ 本单元（视角/取景/表情/动作）→ 一致性绑定 → 零文字与禁止项**。
> 模型实测纪律：听定性/数量/禁止词，不听数值/状态词。数值（占高、尺寸）靠标准格归一，状态（屏幕合上）翻译成外形特征，见 `prompt-rewrite-rules.md`。

## 1. 通用头（每张图前缀，按 profile 微调）

```
皮克斯/盲盒手办质感的 3D 卡通角色，{年龄/职业一句话}，约 5.5 头身、偏写实的少年到年轻成人比例（不是 Q 版二头身、不是吉祥物、不是真人写实照片、不是 2D 扁平插画）；
哑光柔和的皮肤与布料、带细腻柔和光泽；电影感柔和立体主光，轮廓一圈淡淡电光蓝 rim light；纯白摄影棚背景、均匀柔光、脚下柔和接触阴影。
```

风格 token（训练 caption 用英文，提示词中文即可；英文身份块写法见 G14 config 的 identity）。

## 2. 零文字与禁止项（每张图固定结尾）

```
画面中只有这一个角色，除{已登记签名印花，如"胸前 AGI 印花"}外绝不出现任何文字、汉字、字母、数字、标签、人名、标注线、箭头、logo、水印、对话框、标牌、界面窗口、第二个人物、道具（本单元明确要求的除外）；不出现彩虹色、紫粉渐变、霓虹故障、赛博朋克重度光污染、满版噪点。
```

## 3. G1 母版

```
{通用头}
{身份块：发型（颜色/长度/蓬松度/发梢层次/翘发）、脸型、眼睛颜色与大小、眉毛、肤色、上装、下装与裤脚、鞋、配饰有无}
单角色居中、完整全身、从头顶到脚底不被裁切，四周留足安全边距；自然 A 字站姿：双脚与肩同宽、双臂自然垂于身体两侧并微微张开、手心朝内；身体与头部正对镜头，默认自信、亲和的微笑。
纯白背景，无场景无道具。
{零文字与禁止项}
```

## 4. G2 五视图（每格一张，参考图＝母版＋相邻视角）

通用句式：`{通用头}{身份块}，完整全身、与参考图同一角色、同一 A 字站姿与同一套服装发型，{视角外形要点}，纯白背景。{零文字}`

- **正面**：直接复用母版标准格，不另生。
- **前四分之三**：身体与脸转向画面一侧约 3/4，仍能看到完整双臂与双腿；远离镜头一侧的手臂略被躯干遮挡。
- **正侧（面朝画面右侧）**：标准侧面轮廓，只露朝向一侧的耳朵与一只手臂的侧面；鼻、唇、下巴的侧面轮廓清晰；双脚前后错开极小。**显式写"面朝画面右侧"**，并要求另一侧（左侧）轮廓不出现第二组五官。
- **后四分之三**：背对镜头约 3/4，能看到一侧脸颊边缘与一只手臂；后脑勺发型体积、肩背服装结构清晰。
- **背面**：完全背对，看不到五官；发型背面层次、衣领/帽子背面、裤后结构、鞋后跟清晰；双臂垂于两侧、手心朝内只能看到手背侧面。

## 5. G3 基础表情（头肩胸像，配方 A 取景）

```
{通用头}{身份块}，头肩胸像特写，画面下沿自然切在上胸，只拍头、颈、肩与上胸；不要腰、不要骨盆、不要大腿、不要小腿、不要脚、不要全身；身体与脸正对镜头（表情需要时头部轻微偏转），{表情 AU 描述}；纯白背景。
{零文字}
```

- 中性：面部放松、双唇自然闭合、视线看镜头。
- 微笑：嘴角轻轻上扬、闭唇、眼轮匝肌微收。
- 思考：视线偏向画面一侧、下颌微收、头部轻微歪向一侧；**不皱眉、不倒八字眉、不生气、嘴角不下撇**。
- 露齿笑：嘴角上扬、自然张开露出上排牙齿、脸颊上提。
- 惊讶：眉毛上抬、眼睛微微睁大、嘴自然微张；不夸张、不恐怖。
- 严肃：正视镜头、下颌微收、嘴角自然持平；**不怒眉、不眯眼、不咬牙、嘴角不下撇**。

## 6. G4 细节特写（2048 方格，配方 A）

```
{通用头}，极端特写，只拍{部位}，画面中没有脸（眼部/发丝格除外）、没有完整身体、没有其他部位；{该部位的外形与材质描述}；纯白背景。{零文字}
```
- 发丝：头顶到发梢的成簇发丝、自然层次与几缕翘发，哑光发丝有体积。
- 眼部：单/双眼区域，眉毛、眼眶、虹膜颜色与高光；不放大成萌系超大眼。
- 领口：圆领/印花/帽檐等签名上装细节。
- 裤脚/腰头：卷边、抽绳等签名下装细节。
- 鞋：鞋型、鞋底、配色。
- 手部：放松的手、五根手指清晰、指甲与手腕结构正常。

## 7. G5 营销胸像

```
{通用头}{身份块}，头肩胸像、前四分之三视角、身体轻微斜侧、视线看镜头、亲和微笑；构图在头顶与双肩两侧留足余量，适合圆形与方形裁切；纯白背景。{零文字}
```

## 8. G6 动作（全身标准格；C 组在 G7 后做）

```
{通用头}{身份块}，完整全身、纯白背景，{动作：具体到左右手/重心/步态/视线}；服装与发型随动作有自然摆动但款式不变；{手持设备时追加设备防崩段}。{零文字}
```
- A1 挥手：一只手抬起至肩高、掌心向外张开，另一只手自然下垂。
- A2 讲解：一只手抬至胸前掌心向上做示意，视线随手指方向。
- A3 摊开：双手在腰侧摊开、掌心向上、双肩放松。
- A4 抱胸：双臂交叉于胸前、双手搭在对侧手臂、下巴微抬。
- A5 托腮：一只手手肘支撑（无桌时抬至腮边）、手背轻托下巴、头微歪、视线斜上。
- B1 行走：自然步态、一脚在前一脚在后、双臂前后摆动、视线看前方。
- B2 奔跑：大步态、身体前倾、双臂弯曲摆动、一脚离地。
- B3 端坐：**纯文本必崩，必须挂坐姿参考图（配方 C）**；端坐椅面、双脚平放、双膝并拢、双手放腿上，脊柱直立。
- C 组：见 G7 手持关系，设备握在手里、屏幕暗屏化。

## 9. G7 道具

**单体**：`{通用头的材质/光部分}，一个{道具}单体居中，{造型/颜色/材质细节}，无人物、无手持、无场景、纯白背景、柔和接触阴影。{零文字}`（屏幕类道具写"屏幕极暗近黑、不发光"）。

**比例对照**：`{通用头}{身份块}，A 字站姿，{道具}自然握在手中/立在脚边，{尺寸锚点：用头宽/脸宽描述}，纯白背景。{设备防崩段}{零文字}`。

**手持关系**：`…双手{握住/托住}{道具的具体部位}，接触点清晰，全图严格只有两只手、每只手恰好五根手指、手指清晰不融合，禁止第三只手/多余手臂/手指融合畸形；{道具}屏幕极暗近黑、不向背景投射任何矩形光幕…`。

## 10. 风格插槽（G13 用）

- **S1 盲盒 3D（默认）**：即通用头。
- **S2 黏土**：`手工黏土/软陶定格动画质感，表面有细腻手作黏土纹理、哑光、柔和棚拍光、无玻璃反光、无 rim light、纯白底；手部为黏土动画惯例的圆润四指（拇指＋三指）`；身份层（发型轮廓/服装/头身比）与母版一致。
- **S3 赛璐璐 2D（预留）**：`干净描边、平涂赛璐璐阴影、2D 卡通、无 3D 体积光`。
- **S0 超写实（慎用）**：`偏写实 CG 皮肤与布料`，但必须保留"约 5.5 头身、卡通化五官比例"，显式禁止真人照片感。

## 11. 参考图喂料纪律

- 参考图必须**实际传入**图像工具的参考图参数，只在对话里描述不算绑定；每请求单图。
- 母版是所有后续单元的第一参考；视角/表情/道具各自只回指母版与同单元已过门图，不回指链路上的失败图。
- 用户给的外部参考只抽"感觉/材质/配色/服装款式"，不复制其文字、品牌、可识别 IP 与构图；冲突时以规格卡为准并向用户确认。
