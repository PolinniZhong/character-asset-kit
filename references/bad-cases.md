# 崩图 / 事故目录（bad cases）

> 每条四段：**现象 → 根因 → 修法 → 首现门**。新失败重复两次必须回灌本文件并顺延编号。
> 判级口径：**整张能用 / 小崩可修（单格重跑可救）/ 不可用（身份或结构性失败）**；单格失败只重跑该格。
> BC-01–27 整理自早期生产与 210 张受控复现实验；BC-28–33 来自第三个角色 dogfooding 与入库阶段。

## 一、底图与身份（G1–G2）

- **BC-01｜"白底"直出带灰雾与投影**：模型把"白底"理解成棚拍环境，给灰渐变和环境投影。→ 提示词显式写纯白 #FFFFFF 无缝底，且不接受灰雾底，raw 落格时强制抠图重落纯白。G1。
- **BC-02｜文字调比例导致头身漂移**：文字写"六头身"会把盲盒角色拉向真人比例，丢掉手办感。→ 头身比锁进 profile（如 5.5），提示词禁止"写实真人比例"，数值不交给现场发挥。G1。
- **BC-03｜母版背景用深色氛围渐变**：氛围底好看但干扰后续抠图与商卡复用。→ **标准母版统一纯白无缝底**；氛围/场景图是 G12 的事，母版不兼做氛围图。G1。
- **BC-04｜同衣不同光导致配色漂移**：HEX 只写在文字里，各单元光照不同就变色。→ 拼板带 HEX 色板条，关键色升为锁定值，落格后对照色板抽检。G2/G8。
- **BC-05｜背面视角直出成"正面＋背面两个人并排"**：把多格身份板整板当参考，模型复制其多格版式。→ 单单元生成**禁止喂多人整板参考**；需要背面就从身份板裁出单人背面格再喂；提示词顶部固定"有且只有一个人物，禁止并排/多格/第二张脸"。G2。
- **BC-06｜侧面朝向反（镜像）**：左右侧不分，纯文本纠正服从度低。→ 显式写"面朝画面右侧/左侧"并点名可见侧（左耳/左侧轮廓）；逐格目检，镜像单格重跑。G2。
- **BC-07｜数值占高指令不被执行**：文字写"角色占画面 65%"基本无效，模型跟参考图的占高走（实验：参考 65.8% 成片就 65–74%，参考 79% 成片 76–87%）。→ 占高/景别交给参考图与标准格归一，提示词只留定性方向。G1/G2。
- **BC-08｜参考图缺陷被逐参数继承**：带缺陷废稿当参考，构图、肤色暖度、轮廓光、印花全部被继承（两组对照实验证实，方向一致、幅度温和到明显不等）。→ 喂参考前先评估其构图/光色，缺陷明显先修参考图；"不复制参考构图"这句基本无效，要用正向外形描述覆盖。跨门。

## 二、五官、表情与取景（G3–G5、G10）

- **BC-09｜表情 raw 按全身生成，拼板后身腿入镜、脸占比不足**：表情板要求头肩但没在提示词里写死取景。→ raw 阶段固定头肩胸像取景（配方 A），落格走 `--bust`；整批身腿入镜作废重出。G3。
- **BC-10｜要胸像/特写却给全身**：取景边界靠模型默认。→ 配方 A：正向写死"画面下沿自然切在上胸，只拍头颈肩与上胸"＋逐列禁止"腰/骨盆/大腿/小腿/脚/全身"，并用参考图锚定景别（纯文本下特写失败率显著更高）。G3/G4。
- **BC-11｜负面情绪过冲成表情包**：思考/严肃被画成皱眉怒目。→ 固定防过冲句：思考＝视线偏移＋下颌微收＋轻歪头，附"不皱眉/不倒八字眉/不生气/嘴角不下撇"；严肃＝正视＋下颌微收＋嘴角持平，附"不怒眉/不眯眼/不咬牙"；强度靠 AU 叠加不靠拧五官。G3/G10。
- **BC-12｜面部微距被抠图工具剥皮**：系统语义分割把满幅皮肤当背景剥掉。→ 微距 raw 让皮肤铺满画面，外部抠图后用 `--already-cutout` 落格，不走语义分割。G4。
- **BC-13｜肤色在版本间偏暖/偏粉**：肤色跟随参考图暖度，文字"白一点"没有可复现刻度（出现过"再白 15%"被做成惨白）。→ 肤色以 HEX 区间锁定，调色只做小幅步进并以**上一版**为基准描述，不使用绝对化形容词。G1/G4。

## 三、四肢、动作与道具（G6–G7）

- **BC-14｜多一只手 / 手指融合**：手持道具、指屏幕等交互动作高发。→ 数量词写死（两只手、左右手各做什么、五根手指），放大目检手部；崩了只重跑该格。G6/G12。
- **BC-15｜复杂姿态纯文本必崩**：端坐/蹲坐纯文本 0/5（全给宽蹲/盘腿），挂几何参考图 5/5。→ 配方 C：复杂人体几何固定"先出/找一张几何正确参考 → 构图参考＋母版身份参考"二步生成；落格按姿态给 `--scale-factor`（端坐约 0.58）。G6。
- **BC-16｜道具比例失调（手机太大、电脑太小）**：模型对手持物体无稳定尺度，文字数值比例服从度低。→ 以**脸宽/掌宽**为锚做比例对照板，手持关系图过用户目检；盲盒风格允许适度夸张，夸张幅度由人确认后锁定。G7。
- **BC-17｜道具悬空在肩侧、手与物体无接触**：模型回避画握持关系。→ 明确写"整只手掌握住/抱住物体，手指与物体接触、物体贴在掌心/胸前"，禁止悬浮；手持关系不过单格重跑。G7。
- **BC-18｜单体道具姿态废稿（V 形叉开、倾斜）**：单体图模型仍会"摆造型"。→ 单体要正投影、中立摆放、完整不裁；走 `--square --no-shadow`，不与手持图混用。G7。
- **BC-19｜设备/背景被染成发光屏幕**：场景里出现第二块亮矩形，或背景墙变成屏幕光幕（曾出现三只手级别的结构性崩图）。→ 配方 B：把"屏幕合上/锁屏/黑屏"翻译成外形（闭合深色盖板/近黑玻璃矩形，无屏幕面无发光面无界面元素）；背景固定"只有圆形柔光，禁止矩形亮块、禁止第二设备"。G7/G12。

## 四、拼板、文字与工程纪律（G8、跨门）

- **BC-20｜整板直出多视图变脸、视角重复**：单 prompt 多视角一致性仅约 65–75%。→ 路线反转：**逐单元生成、回指母版、脚本拼板**，从工艺上消灭整板直出。G2/G8。
- **BC-21｜标签/说明文字压在角色脸上或资产像素上**：拼板标签内联绘制污染像素，还干扰后续模型识别。→ 铁律：标签一律在画面外（框下/栏外留白区），任何板型不得压像素。G8。
- **BC-22｜拼板细字体发毛、像有线体衬线**：过细的中文黑体在小字号下发虚。→ 统一用无衬线 CJK 字体（macOS 默认冬青黑体；其他平台显式指定可用无衬线 CJK），标签最小字号写进板型。G8。
- **BC-23｜抠图偶发空文件**：语义抠图偶发返回空结果却继续落格。→ 落格前检查产物存在与非空，失败按重试纪律（≤3 次、间隔），仍失败转色键/外部抠图。G4/G7。
- **BC-24｜服装印花/文字在零文字禁止句下漏网**：参考图本身带印花时，纯禁止句偶发失效（实验 60 张漏 1）。→ 零文字禁止句逐图固定且枚举要全（文字/字母/数字/符号/logo/水印）；漏网单格判小崩可修、重跑；母版是否允许固定印花由规格卡显式声明。跨门。
- **BC-25｜横版画幅被模型等比替换**：请求 2560×1440 实际返回 2730×1536（仍精确 16:9）。→ 比例正确即接受，拼板按固定格 contain 吸收；台账记录实际像素，不按请求像素登记。G12。
- **BC-26｜混用模型版本**：中途用非预注册主力模型出探针图，口径不可比。→ 只用 profile 预注册模型；误用批次整批作废、隔离目录、不进统计与资产。跨门。
- **BC-27｜"整张能用"误判**：文字/状态类硬伤曾被一刀切判不可用，与单格可修的事实冲突。→ 口径收窄：单格重跑可修的文字/状态问题归**小崩可修**；只有身份漂移、整格结构性崩坏才判不可用。跨门。

## 五、工具链与入库（dogfooding 与资产中心阶段）

- **BC-28｜系统抠图对深色小道具确定性失败、对面部微距过度分割**：macOS Vision 对深色道具报 `no subject found`（重试无效），对满幅皮肤语义剥皮。→ 三路径：macOS Vision（默认）／`kit_colorkey_cutout.py` 纯白底色键（深色道具兜底）／外部抠图＋`--already-cutout`（微距与非 macOS）；报错必须带 returncode 与兜底指引。G4/G7。
- **BC-29｜道具方格错误参数组合必然裁顶**：`--fig-ratio 0.72 --sole-ratio 0.5` 几何上顶部越界 0.22H。→ 单体统一 `--square --no-shadow`；落格函数对 y<0 直接 ValueError，不静默裁切。G7。
- **BC-30｜CLI 假绿灯**：`--all --char .` 解析为空集却 exit 0 无输出，曾漏登记 28–29 个 PNG。→ `--all` 与 `--char` 互斥报错；枚举为空、库根不存在一律 exit 2 并给改正指引。跨门。
- **BC-31｜清单 meta 内部备注被画到成品上**：板配置的 `meta` 字段是成品文字，不是备注栏。→ 模板 `_comment` 明示；内部备注一律不进清单 meta。G8。
- **BC-32｜微表情板为空情绪族渲染空白行**：可选族 levels 为空仍占行（板高虚高、只有竖排族名）。→ 构建器自动跳过 levels 为空的族，板高按实际族数计算。G10。
- **BC-33｜复用母版当正面用字节拷贝，导致上层资产中心串号**：正面文件与母版字节完全相同，按内容指纹去重的资产系统把两者判成同一身份。→ 正面即使视觉复用母版，也要经标准格**重新落格**产出独立文件（重编码即不同指纹）；已入库才发现则给正面行分配独立身份 ID（身份按路径稳定）。G2/入库。
