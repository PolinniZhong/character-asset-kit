# 风格与门径 Profile（怎么换画风/换流程）

> 本 skill 不绑定任何具体角色或画风。**角色身份**在每个角色包的规格卡里；**画风、门集合、插槽目录、画幅、单元目录**在 profile 里。
> 默认随 skill 发布一个 profile：`profiles/gates-blindbox3d-v1.json`（盲盒手办 3D、白底、5.5 头身、G0–G14）。

## 1. 一个 profile 声明了什么

| 键 | 含义 |
|---|---|
| `profile_id` / `display_name` / `version` | 稳定标识 |
| `head_ratio` | 头身比（blindbox3d＝5.5；Q 版可 2–3，写实向不超过 6.5 并加防真人审查） |
| `material` | 材质语言（皮肤/布料/鞋/光的中文描述，进通用头） |
| `style_token` | 训练 caption 用的稀有风格 token（如 `style3d`）；一个 profile 一个，不与角色 trigger 混用 |
| `background.default` | 资产底（默认纯白）；`world` 段给场景包（G12）的环境口径 |
| `gates` | 门序列：id、名称、是否核心门、产物插槽目录、板型、验收引用 |
| `slots` | 标准插槽目录名（01_母版 … 12_场景包）；换编号体系时整体替换 |
| `canvas` | 各单元画幅像素 |
| `units` | 表情/细节/动作/道具的默认槽位目录（G14 config 的键名要与之一致） |
| `style_slots` | G13 风格变体插槽表（S1 默认风格、S2…） |
| `forbidden` | 该 profile 的固定禁止项（配色、光污染、文字等） |

## 2. 换画风的正确做法

1. 复制默认 profile 为新文件（如 `gates-anime2d-v1.json`），改 id/material/style_token/forbidden；门序列通常不动。
2. 在 `references/` 另写一篇该画风的提示词增量（或在本文件追加章节），**只写与 blindbox3d 的差异**（材质、描边、光影、手部约定等），门径与脚本复用。
3. 第一个新角色就是该 profile 的试水角色：G1 母版过门标准加"盲测剪影"与"防越界"（如 2D profile 防混入 3D 光影、写实 profile 防变真人照片）。
4. profile 稳定后再批量复刻；脚本（落格/拼板/台账/训练集）与画风解耦，一般无需改代码，除非画幅/字体/板底色变化（改 `charkit/boards.py` 或新增板型）。

## 3. blindbox3d 默认 profile 的风格插槽（G13）

- **S1 盲盒 3D（主资产线）**：皮克斯/盲盒手办质感、哑光皮肤布料带柔和光泽、电影感柔光、轮廓淡电光蓝 rim、纯白底；5.5 头身、偏写实少年到年轻成人比例。禁止：Q 版二头身、吉祥物化、真人写实照片、2D 扁平、萌系超大眼、夸张表情包五官。
- **S2 黏土（首个变体）**：手工软陶哑光、手作纹理、柔和棚拍光、无玻璃反光无 rim、白底；**圆润四指手（拇指＋三指）是该插槽明示的风格语言**，不按主资产线五指判崩——任何这类"解剖偏离"都必须在 profile 与提示词里显式声明，不能默认。
- **S3 赛璐璐 2D（预留）**：干净描边、平涂＋赛璐璐阴影、无 3D 体积光。
- **S0 超写实（最后、慎用）**：写实 CG 材质，但保留卡通化头身与五官；每格加防真人化审查。

## 4. 场景世界观（G12 world 段）

默认 profile 给的是一套**克制的深色科技环境**：深色径向渐变空间、3–5 个细小光斑/星芒、微反射地面、极简磨砂或玻璃拟态家具、边缘微光；配色限定深蓝/藏青、电光蓝、白与角色肤色服装色；禁止彩虹色、紫粉渐变、霓虹故障、重度光污染、满版噪点、UI 窗口与第二人物。
换世界观（暖色书房、户外、纯影棚灰等）只改 profile 的 `world` 段与场景母版，门流程不变；场景母版是环境的唯一锚点，先过门再出场景。

## 5. 门裁剪

不是每个项目都要 15 个门。头像/表情包类项目可只启用 G0–G4＋G8；营销物料类加 G5/G12；训练向才需要 G14。裁剪方式：在项目自己的 profile 副本里把 `gates[].enabled` 置 false 并在开工计划里声明，台账门词以库声明/项目约定为准。**不要静默跳门**：跳过的门要在封存小结里写明。

**副本存放约定（v1.1 起）**：profile 副本统一放**库根** `profiles/` 目录，命名 `profile_<profile-id>_<角色代号>_<门范围>.json`，例：`profiles/profile_gates-blindbox3d-v1_CHAR-03_G0-G9.json`；门范围中途扩展时新建一份（如 `..._G0-G12.json`），旧副本保留留痕，并在规格卡 §0 引用当前生效副本。`enabled=false` 的门其 W2（清单声明产物未生成）在封存时按"有意裁剪"人工接受；规格卡 §0 的裁剪声明是权威依据。
