# 门径手册 G10–G14（深度扩展，按需开工）

> 扩展门不阻塞 G9 封存。每个扩展门仍是"参考图回指母版 → 逐单元生成 → 确定性拼板 → 用户过门 → 提示词沉淀"。
> 门是否存在、插槽叫什么由 profile 决定（见 `profiles/gates-blindbox3d-v1.json`）；本篇按 blindbox3d profile 写。

## G10 微表情矩阵（表演扩展）

**目的**：把表情从"6 张定性图"升级为可调度的表演系统：情绪族 × 强度，靠 AU（动作单元）叠加，不靠拧五官。

**首批 4 族 13 格**：E1 喜悦 / E2 惊讶 / E3 思考 / E4 严肃，每族 L1 微弱 / L2 中等 / L3 强烈 三档，＋中性 1 格。选做 E5 难过 / E6 生气（共 19 格），负面情绪最后做。

**取景铁律（实测教训）**：微表情矩阵**只拍头、颈、肩**（头肩胸像，与 G4 同通道），提示词必须显式"画面下沿切在上胸，不要腰/骨盆/腿/脚/全身"——漏了这句模型会把全身和动作都画进来。落格走 `kit_standard_cell.py --bust`。

**强度靠 AU 叠加，不靠放大五官**：
- 喜悦 L1 嘴角轻提＋眼轮匝肌微收；L2 露齿＋脸颊上提；L3 眯眼笑＋头微仰。
- 惊讶 L1 抬眉＋睁眼；L2 ＋嘴微张；L3 ＋吸气、肩微耸。
- 思考 L1 视线偏移；L2 ＋下颌微收、轻微歪头；L3 ＋一手（不，胸像无手——用眉心上提＋视线明确向上侧）。**固定防过冲句："不皱眉、不倒八字眉、不生气、嘴角不下撇"。**
- 严肃 L1 正视＋嘴角自然；L2 ＋下颌微收；L3 ＋眉眼沉稳、嘴角持平。**固定防过冲句："不怒眉、不眯眼、不咬牙、嘴角不下撇"。**
- 选做族同样带防过冲句（难过≠哭到扭曲、生气≠青筋表情包）。
- **空 levels 的族自动跳过**：构建器只渲染 `levels` 非空的族，不占行高；首批 13 格无需手工删 E5/E6（模板保留六族占位，做 19 格时把 levels 补齐即可）。

**流程**：先在服装最简单、无配饰的角色身上试水 E1 三档 → 用户过门 → 补齐 4 族 → build_board `--type micro_expression`。提示词沉淀到 `{CODE}_微表情矩阵提示词_v1.0.md`。

**验收**：每格同一张脸；同族三档强度可排序、跨档不跳脸；没有任何一格被读成别的情绪（尤其思考≠生气、严肃≠愤怒）；无全身混入。

## G11 机位俯仰与视线

**单元**：俯仰 2 张（俯 15° / 仰 15°，全身 A 站姿）＋视线 4 张（左 / 右 / 斜上 / 斜下，头肩胸像）。

**要点**：俯仰改的是**机位**不是姿势——提示词写"camera looking down/up at 15 degrees, same neutral A-pose"，并强调身体结构透视（俯：头顶与肩占比变大、足底仍完整；仰：下颌与躯干底面、不要双下巴夸张化）。视线只动眼珠与少量头部朝向，五官不夸张。参考图回指母版与正侧视图。

**工序**：俯仰走标准格、视线走 `--bust`；build_board `--type gaze`（板内含俯仰与视线两组）。沉淀 `{CODE}_机位视线提示词_v1.0.md`。

**验收**：俯仰各 15° 左右、身份不漂；视线四向明确且眼白/虹膜比例正常；无镜像错误。

## G12 场景包（整幅成图，不抠图）

场景包是把角色放进**世界观环境**的整幅插画，用于头图/封面/营销；与白底资产的区别：白底是"可抠图零件"，场景是"已成图画面"，不抠图、不落标准格。

**目录**：`12_场景包/{场景母版,单图,拼板}`；每场景竖 3:4（1773×2364，角色占高约 55–60%）＋横 16:9（2560×1440，角色在三分线、对侧留压标题负空间）。**横版必须重新构图，禁止竖裁横**。

**流程**：
1. **场景母版先行**：空环境＋A 站姿角色 1 张，锁环境光色/地面反射/光斑密度/角色与环境的融合度；用户过门后才出场景。环境视觉口径来自 **style profile 的 world 段**（默认 blindbox3d profile 给出一套克制的深色科技环境：径向渐变背景、3–5 个细小光斑、微反射地面、极简磨砂/玻璃拟态家具；配色与光污染上限以 profile 为准）。
2. 首批 5 场景建议：SCN-01 工作台敲键盘 / SCN-02 持平板讲解 / SCN-03 坐姿思考 / SCN-04 挥手打招呼 / SCN-05 行走看手机；每场景竖/横各一。场景内手持道具必须与 G7 定稿一致；桌椅显示器是场景专用道具，不进 07。
3. 参考图永远回指"白底母版＋场景母版＋相关定稿动作/表情/道具单图"，不回指上一张场景图。
4. 总览板：`kit_scene_board.py`（两行：竖版主图＋横版头图，场景名仅出现在总览板排版层；单图本体零文字）。

**手持设备专项防崩（含平板/手机/屏幕的场景，原句必带）**：
- "设备屏幕极暗近黑、只有极微弱冷色反光，不发光、不向背景投射光幕/光束/光爆"（唯一场景内桌面显示器可亮屏，但同样不得投矩形光幕）；
- "背景光只是圆形柔和光晕，绝不能出现矩形或方形亮块；没有第二块屏幕/第二台设备/矩形发光面板/投影光幕"；
- "全图严格只有两只手、每只手恰好五根手指、手指清晰不融合，禁止第三只手/多余手臂/手指融合畸形"，写死左右手分工。
- 验收放大目检：手指数、设备数量、设备身后有无矩形亮块。

**验收**：身份不漂；环境口径符合 profile（光斑数量、配色克制、无 UI/文字/第二人物/光污染）；横竖均为完整角色、横版为重构图；人与环境光影统一无拼贴感。沉淀 `{CODE}_场景包提示词_v1.0.md`。

## G13 风格变体（换材质语言，不换身份）

**铁律**：
1. **身份层冻结**：发型轮廓与签名细节、脸型五官、头身比、服装款式与配色关系、签名配饰/印花必须与白底母版一致；风格化只作用于材质/光效/色调/笔触。
2. **风格母版先行**：每个新风格先出 1 张同 G1 构图的白底风格母版，锁材质翻译规则；母版不过门不派生。
3. **白底中性环境**：风格母版与派生单体一律纯白底，不带世界观环境（"某风格＋场景"走 G12 另立）。
4. 逐单元生成、脚本拼板、资产本体零文字（登记过的签名印花为例外，可用同材质浮雕感表达但字形不变）。

**插槽表（blindbox3d profile 默认）**：S1 盲盒 3D 即主资产线、不重复生产；S2 黏土 claymation（首个变体，哑光软陶、柔和棚拍光、无玻璃反光无 rim；**手部采用黏土动画惯例的圆润四指（拇指＋三指），这是该插槽的风格语言，不按主资产线五指判崩**——此类偏离必须在 profile 与提示词中显式声明）；S3 赛璐璐 2D（预留：平涂＋赛璐璐阴影＋干净描边）；S0 超写实（最后可选，严防越过头身比变真人）。新插槽先在 profile 登记并补"材质翻译规则"再出图。

**材质翻译规则模板**（每插槽必填）：表面材质（哑光/高光/纹理）→ 五官与发丝如何用该材质重述 → 布料/鞋如何塑型 → 光色语言（几盏光、有无 rim、背景）→ 明确禁止项（如黏土风禁电光 rim 与玻璃反光）。

**流程**：风格母版（只喂白底母版，不喂场景图）→ 过门 → 首批派生（五视图＋中性/微笑两表情，够用即停）→ `kit_style_board.py --slot S2-黏土` 五视图板 → 沉淀 `{CODE}_风格变体提示词_v1.0.md`。试水角色选服装最简单的那个。

**验收（盲测法）**：风格母版与 G1 母版并排，不看材质只看剪影/发型/服装应立刻认出同一角色；头身比不漂；全身材质语言统一（不能脸是黏土、衣服还是塑料）。

## G14 训练素材备料（数据集工程，不在库内训练）

**边界**：本门只做数据集（选图、命名、caption、切分、清单、校验），LoRA 训练在库外（kohya-ss/sd-scripts、ostris ai-toolkit 等）。数据集是派生物，可整体删除重建，原始资产不动。

**一次性配置**：把 `templates/trainset.config.example.json` 复制为角色包 `11_训练素材/trainset.config.json`，填写：`code / trigger（稀有自造 token）/ style_token / gender / master_rel / identity（完整英文身份块）/ expr（六槽位英文映射，键名与 G3 文件名一致）/ detail（六槽位）/ val_slugs / pose / held（可选覆盖）`。

**选图（S1 白底核心集，约 47 张）**：
- 纳入：母版 1（full）；五视图去正面 4＋俯仰 2（full）、视线 4（face）；基础表情 6＋微表情 12（face）；细节 6（face）；营销胸像（face）；动作 8（full）；手持关系 3（medium）。
- 排除（硬规则）：拼板/总览板/商卡/验收版、`_透明`、单体道具与配饰、场景包、风格变体、过程稿、任何画面内文字图（登记过的签名印花除外）、与母版近重复的多视图正面。
- 取景配比：face 约 60%、medium、full 保留（IP 必须学全服装与比例，不删全身图），用差异化 repeats 控剂量（face 12 / medium 8 / full 6 起点）。

**双 caption profile（一次导出两套）**：
- profile-A（ai-toolkit/Flux 等现代底模，默认）：`default_caption.txt` 写一次完整身份块；img/ 同名 sidecar 只写"触发词＋变量块"；白底显式写进身份块（`plain white studio background`），便于推理时替换。
- profile-B（kohya/SDXL）：`cap_kohya/` 每图写"身份块＋变量块"全量句。
- sidecar 一律英文；触发词所有 caption 拼写完全一致；中文释义只进 manifest。

**切分与验证**：val 固定 5 张分层（母版/正侧/微笑/行走/眼部细节，slug 在 config 里）；附 5 条固定 smoke prompt（正脸微笑/正侧全身/A 站/挥手/户外泛化）；先 1000–1500 step 试水再全量（2000–4000 step、rank 16–32、LoRA 强度 0.8 起调，均为起点不是承诺）。

**命令**：
```bash
python3 scripts/bin/kit_trainset.py --root <库根> --char <包目录名或路径> --build
python3 scripts/bin/kit_trainset.py --root <库根> --check      # 字节哈希/双 caption/val/禁入来源全检
```
产物在 `11_训练素材/datasets/S1-盲盒3D_v1.0/`，自动生成 `.lora-audit-ignore`（向审计工具声明分桶分辨率等既定设计）。不同风格/环境绝不混训，需要时另立插槽目录。
