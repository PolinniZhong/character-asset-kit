# Profile 增量：真人写实风（gates-realhuman-v1）

> 本篇只写**真人写实 profile 与默认 blindbox3d（3D 盲盒）的差异**。门序列 G0–G14、确定性脚本、板型、六段式沉淀、台账流程**完全复用，不再重复**。
> Profile 本体：`profiles/gates-realhuman-v1.json`。换 profile 的通用规则见 `style-profiles.md`。

## 1. 何时选这个 profile

- 要做**真人写实/摄影质感**角色（都市剧、短剧真人卡、写实数字人参考）时选它；
- 要做 3D 卡通/盲盒/黏土/2D 时用 blindbox3d 或其 style_slots；
- 两条线是**同一 Skill 的两个 profile，不是两个 Skill**。

## 3. 核心知识：真实皮肤方法论（最重要）

真人线最大的坑是把皮肤画成"**塑料 / 打蜡 / 专业精修瓷脸**"。三版迭代确立的口径：**v2「干净的真实」是唯一标准**。

### 3.1 三件套（必须同时具备）

1. **点名纹理词**（让模型显式生成微观结构）：
   - 自然毛孔与皮纹颗粒；脸侧鬓角极细绒毛；
   - 男性角色：**刚刮净的极淡青色胡茬影**（下颌/上唇/两颊，**不浓密、不连片、不邋遢**）；
   - 鼻周、耳侧轻微自然泛红；
   - 鼻头、额头、手背：**自然皮脂的微弱哑光油光**（这是"活皮肤"，区别于打蜡/瓷釉高光）；
   - 肤色有真实细微不匀，可有极淡小痣。
2. **换光学口径**（比加形容词更有效）：
   - 全画幅 **85mm f/1.8**、**Kodak Portra 400** 质感＋**轻微**胶片颗粒；
   - 纪实人像、**RAW 原片直出、零磨皮零美颜**；
   - 有方向的窗光（见 §4）。
3. **强负向**（逐字固定）：
   - 塑料 / 打蜡 / 瓷釉 / 陶瓷 / 娃娃 / 橡胶皮肤、蜡像感；
   - 磨皮、美颜、Airbrush、光滑无瑕、均匀假脸、数字 HDR、油腻高光；
   - 3D / CGI、插画 / 动漫 / 赛璐璐；
   - 密胡茬 / 根根短须 / 连片胡茬、满脸瑕疵痘印、泛黄发暗、蜡黄沧桑。

### 3.2 三版结论（真人线教训，务必记住）

| 版本 | 做法 | 结论 |
|---|---|---|
| v1 | 平光精修、均匀无瑕 | ❌ 塑料/打蜡 |
| **v2** | 干净的真实（轻纹理、极淡胡茬、自然哑光） | ✅ **采用** |
| v3 | 加密胡茬＋重瑕疵＋重肤色 | ❌ "太假太黄" |
| v2.1（2026-09-24 微调） | 正面光下加强"毛孔开口/肤色不匀/绒面质感"描述 | ❌ 盲评未通过：放大看"燥＋光滑"的蜡感，不如 v2 |

> **关键认知：真实 ≠ 密胡茬 / 满脸瑕疵 / 蜡黄沧桑。** 都市主角要"干净、帅气、真实"三者并存。加瑕疵是手段不是目的，过犹不及。
>
> **v2.1 迭代教训**：单纯在提示词里加强毛孔/肤色不匀词，模型可能把"毛孔开口"理解成一种**均匀的微噪点（燥）叠加在光滑底上**，而不是真实皮肤的随机纹理——结果是"近看发燥、底子仍光滑"的蜡感，比 v2 更假。**正面光下皮肤蜡感的瓶颈很可能在 seedream_5.0_pro 模型本身，提示词迭代到 v2 已接近天花板。** 后续若要继续突破皮肤真实感，方向应转向：①换/升级生图模型；②后期叠加真实皮肤纹理（确定性后处理）；③用真实皮肤照片做质感参考图（参考图通道＞文字通道）；而不是继续在文字描述上加码。

### 3.3 改质感必须用"质感已正确"的图当锚

参考图通道 ＞ 文字通道。要升级皮肤，就以**皮肤已经对的那张**为身份/质感锚；在"塑料锚"上用文字喊"真实"基本无效。改回某属性同理——换用"该属性本来就对"的图当锚，而不是在错锚上用文字纠正。

## 4. 光分景别（真人线特有，决定皮肤与服装成败）

> **光照口径已根据 2026-09-24 盲评 A/B 回灌**：正面柔光 vs 右前方 45° 侧窗光各出一张胸像，用户盲评选择正面光（更精致、更符合都市主角定位）。

- **胸像 / 面部特写（G3、G5、G4 面部格、G11 视线）**：默认用**正面柔和棚光**——面部两侧亮度一致、无明显阴影、五官干净精致，这是都市主角的默认光；
  - 权衡记录：45° 侧光确实更显毛孔与皮肤立体感，但会让面部有明暗过渡、牺牲精致度；用户实测优先"精致"。
  - 折中：需要兼顾皮肤质感时，可用**正面为主、带极轻微方向（约 10–15°）的柔光**，而非 45° 侧光。
  - 侧光的适用场景：纪实风、需要强调皮肤质感/沧桑感的配角或特定情绪镜头，不作为都市主角默认。
- **全身（母版、五视图、G6 动作、G7 手持、G13 造型、G11 俯仰）**：用**正面为主、轻微方向的柔和窗光**——干净均匀，**不用强侧光**，避免：①半脸暗；②白底投影；③各角度服装色不一致。

## 5. G13 在真人线＝造型变体，不是材质变体

- 真人线的"风格变体"是**换服装/造型（different outfits）**：默认造型之外，可做商务正装、休闲日常、运动等（见 profile `style_slots` R1–R4）；
- **身份层冻结**：发型签名、五官、头身比、签名配饰一律不变；
- 仍遵循"**造型母版先行 → 过门 → 派生五视图 → kit_style_board 拼板**"；白底中性环境，不混场景。

## 6. G12 场景：现实都市 world

- world 段是**现代都市写实**（街头、写字楼/公寓、咖啡厅、通勤），具体城市/季节由规格卡定；**不是** 3D 的深色科技空间；
- 其余场景纪律（场景母版先行、横竖各一、横版重构图、手持设备防崩）同 `gates-g10-g14.md G12`。

## 7. 落格与抠图的真人专项

- **毛发边缘**：发际线、碎发、鬓角必须放大检查 subjectmask 是否啃边；真人毛发比 3D 更易出错；
- **面部微距（G4 面部格）**：让皮肤满幅到四边、五官不悬空，raw 直接 `kit_standard_cell.py --already-cutout --square`，**跳过 Vision**（它会把面部微距的皮肤当背景剥掉、或 no subject）；
- **深色道具** Vision 失败 → `kit_colorkey_cutout.py` 色键兜底，再 `--already-cutout`；
- **接触阴影用中性灰**（profile canvas 给定），避免 3D 的微蓝阴影在真人白底上显脏；
- **Vision 连发会拖死执行后端**：落格分批（≤2–3 张/命令）、逐张间隔，勿一次性连发。

## 8. 取景高频坏例（真人线）

### 8.1 胸前持物 / 插兜缺脚
- **双手前伸 / 插兜 / 手持道具举到胸前**，会稳定诱发"大腿以上中景、缺小腿和脚"；
- 道具**垂在低位、贴腿侧**则一次成全身；
- **修法**：把"远距离、完整全身、头顶到双脚鞋底、严禁近景/半身裁切腿脚"的取景句写到 **prompt 最前面**；崩了单格重跑。

### 8.2 胸像肩峰贴边 / 单侧肩"消失"（L2 实测发现，2026-09-24）
- 头肩胸像（G4 表情、G5 营销胸像、G11 视线）raw 构图若主体偏一侧，会出现**一侧肩峰几乎贴画面边缘、视觉上像"那侧肩膀没有了"**；
- 真人胸像比 3D 更易中招（真人肩宽、头发外扩，raw 居中时肩外侧留白天然少）；
- **修法（胸像取景句必带）**：
  1. 写"**头肩胸像，双肩完整入画，左右肩峰外侧各留约一个头宽的安全边距，肩峰不贴画面边缘**"；
  2. 配合配方 A 的下沿切上胸句（"画面下沿自然切在上胸，只拍头、颈、肩与上胸"）；
  3. 落格时若 raw 肩峰已贴边，用 `kit_standard_cell.py --bust` 的 bbox 调宽（或重跑该单元），**不要把贴边图直接当成品**；
- **验收加查**：胸像过门时逐张看"双肩是否都在、肩峰是否贴边"，这是真人线胸像的必查项。
