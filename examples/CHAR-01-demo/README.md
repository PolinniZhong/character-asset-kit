# CHAR-01-demo · 脱敏成品板样例

这里是一套**真实产线输出的脱敏成品板**：它们来自一次完整的 dogfooding 自用验证（全新对话只靠本 Skill 跑完 G0–G12），
角色代号、规格卡、私有命名已全部移除，统一替换为虚构代号 `CHAR-01-demo`。画面内只保留模板自动生成的通用格标签
（如「正面」「A1 挥手」「SCN-01」）与 HEX 色板，不含任何人名、项目名、路径或水印。

> 只随仓发布**干净版**拼板（无标注线），因此对该目录跑台账对账会出现 7 条 W2（验收版未生成）——这是预期现象，不是缺陷。
> 原始 raw 单图、规格卡与过程稿不随仓发布。

## 这些图想说明什么

- **版式是脚本确定的，不是模型一次画成的**：每格单独生成、放大目检、崩格单格重跑，再由 `kit_build_board.py`
  等确定性脚本落格拼板；标签永远在画面之外，不压角色像素。
- **同一身份签名贯穿全部板型**：同一发型、脸型、服装、5.5 头身比例，跨角度 / 表情 / 动作 / 场景不漂移。
- **画风可换**：本样例是默认 profile（皮克斯 / 盲盒手办感 3D）；换 profile 后门径与脚本不变。

走查命令序列见上层 [`../README.md`](../README.md)；验证过程的缺口与返工统计见
[`../../docs/DOGFOODING.md`](../../docs/DOGFOODING.md)。
